The complete spinner collection

Every set in one place: 63 spinners, each a single animated SVG string for an Image control's Image property. Pick a color, open a spinner, copy its Power Fx.

Using these in an app

  1. Add an Image control and paste a formula into its Image property.
  2. Set ImagePosition to ImagePosition.Fit and keep the control square. The SVG scales to any size without blur.
  3. Point the color at your theme, for example {c: varTheme.Accent}, with the value as a hex string.
  4. Bind Visible to your loading flag. The animation restarts each time the control appears.
  5. Adjust speed by editing the dur values inside the string. Nothing else needs to change.
